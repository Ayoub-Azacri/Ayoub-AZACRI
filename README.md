### 🚀 À propos de moi

- 🔭 **Projets récents :**
  - **[Walmart Retail Lakehouse](https://github.com/Ayoub-Azacri/Walmart_Airflow_Dbt_Project)** : Architecture Medallion sous Databricks avec Unity Catalog, Delta Lake, CDC PostgreSQL, dbt Core et Airflow 3 conteneurisé.
  - **[Spotify Real-Time Streaming](https://github.com/Ayoub-Azacri/spotifydata-project)** : Pipeline événementiel à haut débit (>1 000 évt/s) sous Apache Kafka (KRaft), Spark Structured Streaming, Redis cache et MinIO S3.
  - **[ELK Movies Platform](https://github.com/Ayoub-Azacri/elk-movies-platform)** : Moteur de recherche et analytique sur 770k films sous Elasticsearch 8, Logstash, Kibana et Flask.
  - **[Enterprise SQL Data Warehouse](https://github.com/Ayoub-Azacri/sql-data-warehouse-project)** : Ingestion ERP/CRM et modélisation en étoile Kimball sous SQL Server (T-SQL).
- 🛠️ **Ce que j'apporte :** Rigueur du Software Craftsmanship (POO, Clean Code, CI/CD, tests automatisés Pytest), pipelines scalables et architectures de données production-ready.
